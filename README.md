# Kellyposh Crochet Showcase

Build a responsive crochet sales WEBPAGE - single page website.

Business Name: Kellyposh Crochet

Location: Minna, Nigeria

Goal: Sales showcase webpage to sell handmade crochet items via WhatsApp.

Design: Luxury, soft, warm, Pinterest aesthetic. Background cream #FFF8F0, text brown #5C4033, accent pink #FFDAB9. Rounded cards, soft shadows, fully mobile responsive. This is a webpage, not an app.

Structure:

1. Navbar with logo "posh crochet" and links: Home, Shop, Custom Order, Contact + Cart icon

2. Hero: Headline "Handmade Crochet With Slow Love" + 2 buttons "Shop Now" and "Chat on WhatsApp" + big crochet image

3. Categories: 6 cards - Bucket Hats, Bags, Tops, Dresses, Beanies, Baby Sets

4. Shop Section: 8 products grid. Each card has image, name, price in Naira, rating, and "Order on WhatsApp" button that opens wa.me link with product name pre-filled

5. Custom Order Form: Name, Item, Color, Size, Date, then sends to WhatsApp

6. Reviews: 3 customer reviews from Abuja

7. Footer: Instagram, WhatsApp, Location, Copyright "Frontend Project 2026"

Use React + Tailwind, create products.js file for products, make code clean for GitHub.
